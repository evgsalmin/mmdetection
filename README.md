# Цель

Вам нужно дообучить две модели: **FCOS** и **YOLO**. Вы обучите их распознавать основные классы мобов в *Minecraft* (например, корова, зомби и т. д.).

Вам нужно провести инференс моделей на видеопотоке, чтобы визуально оценить работу моделей, а также сравнить их по ключевым метрикам **mAP** и **FPS**.
